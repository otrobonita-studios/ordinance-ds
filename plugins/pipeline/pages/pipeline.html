Pipeline

A pipeline runs the checks on every change, so that nobody has to remember them. Ordinance DS has a template that uses no code from others.

1

The template

The template is a workflow for GitHub Actions. It runs the build, the check and the unit tests. Open the template

Every step of the template is a command. It uses no action from another project, so the pipeline has no third-party code to review.

Ordinance DS uses a copy of the template as its own pipeline. The check fails when the two files differ.

The template has not run in a live pipeline yet. Test it in your repository before you rely on it.

2

Use it

  1. Copy the file to .github/workflows/check.yml in your repository.
  2. Require this check before a change can be merged.
  3. Require a review by a second person.
  4. Turn on the scan for secrets in your code host.

The last three steps are settings of your code host. Ordinance DS cannot set them for you.

3

What a pipeline adds

The check proves a rule at one moment. A pipeline leaves a record that the rule held at every change.
