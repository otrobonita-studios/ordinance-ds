Built with

This page lists the sites that are built with Ordinance DS. It also shows the mark that such a site can carry.

1

The sites

A site is listed as planned until it has a public address. Then its row gets a link.

2

The mark

A site that is built with the framework can say so in the foot of its pages. The mark is one line of text.

Built with Ordinance DS

<p class="ord-built">Built with Ordinance DS</p>

The mark is a choice. The licence asks only that its own text stays with the code.

Ordinance DS has no public address yet. When it has one, the mark becomes a link to it.

3

Add a site

Add a row to the file plugins/built-with/sites.json, and build again.

The mark says who built the site. It does not say that the site meets a law or a standard.
