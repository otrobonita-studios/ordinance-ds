Data

A page gets its data in one way. That makes it possible to check the data before the page shows it.

1

Data in the page

A page carries its data as a block of JSON. The script ord-data.js reads the block and checks it against a schema.

Data that fits becomes a table. The script writes every value as text, so data can never become code.

The table appears here when the script has checked the data.

The script writes the result of the second example here.

The second block has a text where a number must be. So the script refuses it, and the notice above says why.

2

Data from a server

The function ordData.load asks a server for data. It accepts an address on the site's own server and refuses every other address.

It is the only code in Ordinance DS that may use the network. No page calls it today, because Ordinance DS has no server.
