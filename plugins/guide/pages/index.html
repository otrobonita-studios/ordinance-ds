Ordinance DS

Ordinance DS is a web starter pack and a minimal design system for regulated products. A test checks every rule that this page calls checked.

1

What it is

Ordinance DS gives a team a strict start for a website or a product. It is a set of design tokens, a stylesheet, a build and a set of checks.

It has a strict security policy, self-hosted assets, and components built to WCAG 2.2. It also has conventions that an AI agent can follow, and defaults that an auditor can check.

A design system used to be a library of finished screens. Ordinance DS is a base instead: an organisation and its AI agents build their own product on it.

It keeps to the rules that a test can measure, such as contrast, names, requests and checksums. The check then says whether a change still keeps them.

The framework does not make a product meet a law. It says what it does, and it shows how each statement is checked.
