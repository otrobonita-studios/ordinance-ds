Core

The core is everything that the site cannot build without. Every other part is a plugin, and a plugin can be taken away.

What the core contains

The shell

The build writes the menu from the pages of the plugins. Adding a page to a plugin adds an item to the menu.

The menu and the help are parts of HTML that open without a script. On a narrow screen the menu opens from a button.

The page is one centred column. Its widest line of reading text is 42 rem.

3

Made for a new developer and for an agent

A change can be checked without asking anyone. Three choices make that possible.

  • The rules for a change are in one file, AGENTS.md.
  • Every fact has one source: the tokens, the names, the rules and each plugin's own file.
  • Every failure of the check names the rule, the file and the reason.
4

Add a language

The pages exist in English only. The build can write the site in more languages, and these steps add one.

  1. Add the code of the language to languages in site.json. The first language in the list is the main one.
  2. Copy strings/en.json to a file with the code of the language, and translate its texts.
  3. In a plugin, put the translated pages in the folder lang/sv/pages, where sv is the code. Use the same file names.
  4. Beside that folder, titles.json holds the titles for the menu, and help.json holds the help.

The build writes each added language into its own folder, and the menu links each page to its other languages.

A page without a translation shows the main language, and its markup says so.
