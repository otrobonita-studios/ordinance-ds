Secure by default

A page of Ordinance DS runs no code that is written into it, and it loads nothing from another server. The check enforces both.

1

In the pages

  • A page has no style attribute and no style element.
  • A page has no script that is written into it, and no event attribute.
  • A script is a file that a plugin declares for a page.
  • Code that writes HTML from data is refused, for example innerHTML and eval.
2

Headers from the server

A server sends these headers with every page. The first one is the Content-Security-Policy.

The policy has no exception for inline styles or inline scripts, because the pages have none.

3

Where the headers are used

The local server sends the headers. The browser test opens every page under them, and fails when the browser blocks anything.

Headers do not decide who may read a page. Access control is on the page Excluded.
