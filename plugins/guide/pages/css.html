CSS

The stylesheet is one file that the build writes. Its values come from tokens, and its names follow one contract.

1

Layers

The stylesheet has five layers, in this order.

@layer ord.reset, ord.tokens, ord.base, ord.parts, ord.utilities;

A later layer wins over an earlier one. So no rule needs !important, and the check refuses it.

2

Colour tokens

A colour is named by its role. The system of the reader chooses the light or the dark theme.

A page can fix one theme with the attribute data-theme on the html element.

3

Other tokens

Sizes are in rem, so the page follows the text size that the reader has chosen.

4

Typefaces

The three typeface tokens name Noto Sans, Noto Serif and Noto Sans Mono. Their files are in the folder third-party/fonts, so the pages ask no other server for a typeface.

  • The file tokens/fonts.json lists each file with the characters that it covers.
  • The build writes one @font-face rule for each file. The browser loads a file only when a page uses its characters.
  • Each token ends with a typeface of the system. The page uses it until the file has loaded, and when the file does not load.

A product changes the three tokens and the list of files to use its own typefaces.

5

A theme

A product gets its own look from one file, tokens/theme.json. The file holds only the tokens that the product changes.

{
  "color": {
    "accent": { "$value": { "colorSpace": "srgb", "components": [0, 0.35, 0.3], "hex": "#00594d" } }
  },
  "radius": {
    "sm": { "$value": { "value": 0.375, "unit": "rem" } }
  }
}
  • The file tokens/theme.dark.json does the same for the colours of the dark theme.
  • A theme can change a token. It cannot add one, and the build stops when it tries.
  • The check measures the colours of the theme. A theme with too little contrast does not pass.

Ordinance DS has no theme file of its own. The pages that you read show the tokens as they are.

6

Utilities

The check refuses a style attribute, and the security policy blocks it. A utility class does the same small job with a name.

Boldsmall and quietat the end, in the typeface for code

  • A utility does one thing, and its value is a token. So a utility cannot bring in a colour or a size that the check does not know.
  • The utilities are the last layer. A utility wins over a part, and no rule needs !important.
  • The set is small on purpose. When a page uses the same utilities together again and again, make a part with a name.
