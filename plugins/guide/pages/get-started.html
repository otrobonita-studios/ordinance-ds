Get started

Build the site, check it, and open the first page. You need Node.js 20 or later and nothing else.

1

Build and check

  1. Open a terminal in the folder of Ordinance DS.
  2. Build the site with the first command below.
  3. Check every rule with the second command.
  4. Open dist/index.html in a browser.
node scripts/build.mjs
node scripts/check.mjs
Start-Process .\dist\index.html

The commands are written for PowerShell. The two node commands are the same in every terminal.

2

Serve the site with the security headers

The local server sends the headers that the page Secure by default lists. It answers only on your own computer.

node scripts/serve.mjs

Every page also opens from the folder, without the server. A page that asks a server for data needs the server.

3

Change something

  1. Edit a source: a token in tokens/, a rule in src/css/, or a page in a plugin.
  2. Register a new name in names.json before you use it.
  3. Build, and then check.
  4. Read the result. A failure names the rule, the file and the reason.

Never edit a file in dist/. The build writes that folder again each time.

4

Test more

Two more commands test the parts that the check cannot see.

node --test
node scripts/browser-test.mjs

The first runs the unit tests. The second opens the built pages in a browser without a window.
