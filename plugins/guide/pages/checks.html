The rules

2

The five ways to test

The pipeline also measures how much of the code the unit tests run. It fails under 90 of 100 lines, 80 of 100 branches, or 90 of 100 functions.

That number counts only the files that the unit tests load. The check itself, the local server and the history check are tested by running them, and they are not in the number.

3

A rule and its page

A page says checked only for a rule in this list.

The check fails when a rule in the list has no code, and when code has no rule in the list.
