Software bill of materials

A software bill of materials (SBOM) lists every component of a piece of software. The build writes one for Ordinance DS each time it runs.

1

The file

The file is sbom.cdx.json, in the CycloneDX format, version 1.6. Open the bill of materials

The file has no date and no random number. So the same sources always give the same file.

2

What it lists

When a typeface or an icon is added to the folder, it appears in this table and in the file.

3

How it is checked

The check compares the file with the list of third-party files. It fails when a component or a file is missing.
