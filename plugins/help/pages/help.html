Help

Every page has help that opens beside it. This page explains how the help works.

1

Open and close

The Help button is at the top of the menu. It opens a panel at the right edge of the screen.

The panel stays open while you read the page. Close it with its own button.

On a wide screen the page makes room for the panel, so the panel covers nothing.

2

Where the text comes from

Each plugin has a file help.json with the help of its pages. The build writes the panel into each page.

The check fails for a page without help.

3

No script

The panel is a part of HTML that is called a popover. It opens with the mouse and with the keyboard, and it needs no script.
